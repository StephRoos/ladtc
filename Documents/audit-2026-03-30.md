### Build : 🔴 ÉCHOUE

```
Error occurred prerendering page "/team"
PrismaClientKnownRequestError: ECONNREFUSED
```

**Cause** : la page `/team` (`src/app/(public)/team/page.tsx`) est un Server Component qui appelle `prisma.user.findMany()` directement. Pendant le build statique (sans base de données), cette requête échoue.

**Fix** : Ajouter `export const dynamic = "force-dynamic"` ou wrapper le fetch dans un try/catch avec fallback vide.

### ESLint : ⚠️ 4 erreurs, 15 warnings

- 1 erreur réelle : `EventForm.tsx:55` — `watch()` incompatible avec les règles react-hooks
- 3 erreurs + 12 warnings dans `src/generated/prisma/` (code généré, à ignorer via .eslintignore)

## 7. Comment tester le projet

### Prérequis
```bash
# Installer les dépendances
pnpm install

# Copier l'environnement
cp .env.example .env.local
# Remplir les variables (DATABASE_URL, BETTER_AUTH_SECRET, etc.)
```

### Base de données locale (Docker)
```bash
# Lancer PostgreSQL
docker compose up -d postgres

# Appliquer les migrations
npx prisma migrate dev

# (Optionnel) Seed avec données de test
npx prisma db seed
```

### Lancer les tests
```bash
# Tests unitaires (272 tests)
pnpm test

# Tests en mode watch (développement)
pnpm test:watch

# Tests avec couverture
pnpm test -- --coverage
```

### Lancer le serveur de développement
```bash
pnpm dev
# Ouvrir http://localhost:3000
```

### Vérifier le build
```bash
# Build de production (nécessite la base de données pour /team)
pnpm build

# Lancer en mode production
pnpm start
```

### Lint et type-check
```bash
# ESLint
pnpm exec eslint src/

# TypeScript type-check
pnpm exec tsc --noEmit
```

### Tester le paiement Stripe
```bash
# Lancer le webhook Stripe en local
stripe listen --forward-to localhost:3000/api/stripe/webhook

# Utiliser la carte de test : 4242 4242 4242 4242
```

### Parcours utilisateur à vérifier manuellement
1. **Inscription** : `/auth/register` → email de bienvenue → login
2. **Profil** : `/profile` → modifier nom, contact d'urgence, avatar
3. **Équipement** : `/equipment` → ajouter au panier → checkout → confirmation
4. **Cotisation** : `/membership/pay` → paiement Stripe → statut ACTIVE
5. **Blog** : `/admin/blog/new` → créer article → vérifier `/blog/[slug]`
6. **Événement** : `/admin/events/new` → créer → s'inscrire depuis `/events/[id]`
7. **Admin** : `/admin/dashboard` → vérifier stats, logs, graphiques
